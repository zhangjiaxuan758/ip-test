常见问题

什么是 DNS 泄露？

用 VPN 时，DNS 查询也应该走 VPN。如果这里列出的 DNS 服务器属于你的运营商而不是 VPN 服务商，运营商仍然能看到你访问了哪些网站，这就是 DNS 泄露。

这个检测是怎么做的？

浏览器会解析我们托管的 DNS 区域下几个随机主机名。这些名字不在任何递归服务器的缓存里，它们只能直接查询我们的权威服务器，我们记录每次查询的来源地址，两分钟后自动删除。

为什么会出现好几个地址？

Google Public DNS、Cloudflare 这类大型公共 DNS 会从很多台机器发出查询，同一个网络出现好几个地址是正常的。检测还会分别走 IPv4 和 IPv6，同时支持两者的服务器可能出现两次。

客户端子网（ECS）是什么？

有些 DNS 服务器（比如 Google Public DNS）会把你 IP 地址的一部分传给权威服务器，让 CDN 挑离你近的节点。如果你的 DNS 这样做了，这里会显示它传出的网段。

为什么结果和我设置的 DNS 不一样？

浏览器开了安全 DNS（DNS over HTTPS）时会绕过系统的 DNS。路由器和运营商的 DNS 也常常把查询转发给上游服务器，这里看到的就是上游。
